# PHPUnit Model Knowledge Patch

Система накопления и консолидации знаний о PHPUnit для повышения качества генерации тестов.

## Проблема

Языковая модель обучена на большом объёме PHPUnit-кода, но тренировочные данные содержат устаревший API. Без коррекции модель:

- Использует removed/deprecated вызовы (особенно те, что не выбрасывают runtime warning).
- Не знает о новых assertions и атрибутах.
- Допускает поведенческие ошибки (behavior traps).

## Решение

Model Knowledge Patch — компактный файл с правилами вида «не пиши X → пиши Y», подключаемый к скиллу. Модель читает его перед генерацией тестов и использует актуальный API.

## Структура директории

```
build/PHPUnit/
├── README.md              ← этот файл
├── COLLECT.md             ← инструкция: обновление дельта-патча
├── BUILD.md               ← инструкция: консолидация в full-файл
├── PHPUnit9.md            ← дельта-патч (заморожен)
├── PHPUnit10.md           ← дельта-патч (заморожен)
├── PHPUnit11.md           ← дельта-патч (заморожен)
├── PHPUnit12.md           ← дельта-патч (заморожен)
├── PHPUnit13.md           ← дельта-патч (обновляется при минорных релизах)
├── PHPUnit13-full.md      ← консолидированный патч (генерируется)
└── PHPUnit13/             ← исходники: ChangeLogs, DEPRECATIONS
    ├── ChangeLog-13.0.md
    ├── ChangeLog-13.1.md
    ├── ChangeLog-13.2.md
    └── DEPRECATIONS.md
```

## Поток данных

```
ChangeLogs + DEPRECATIONS (кладутся вручную в PHPUnit13/)
        │
        ▼
  [COLLECT.md] → обновляет PHPUnit13.md (дельта-патч)
        │
        ▼
  PHPUnit9.md + 10.md + 11.md + 12.md + 13.md
        │
        ▼
  [BUILD.md] → генерирует PHPUnit13-full.md (консолидированный)
        │
        ▼
  Скилл phpunit-tests подключает PHPUnit13-full.md
```

## Процесс обновления (минорный релиз)

1. Обновить PHPUnit в проекте (composer).
2. Положить новые/обновлённые ChangeLogs и DEPRECATIONS в `PHPUnit13/`.
3. Запустить процесс COLLECT — агент дополнит `PHPUnit13.md`.
4. Запустить процесс BUILD — агент пересоберёт `PHPUnit13-full.md`.

## Процесс перехода на новую мажорную версию

1. Заморозить `PHPUnit13.md` (больше не редактируется).
2. Удалить директорию `PHPUnit13/`.
3. Создать директорию `PHPUnit14/` с исходниками новой версии.
4. Создать `PHPUnit14.md` (запустить COLLECT с нуля).
5. Запустить BUILD — будет сгенерирован `PHPUnit14-full.md` из всей цепочки 9→14.
6. Обновить скилл: подключить `PHPUnit14-full.md` вместо `PHPUnit13-full.md`.

## Подключение к скиллу

Консолидированный файл (`PHPUnit13-full.md`) подключается как knowledge-файл к скиллу `phpunit-tests`.

В скилле добавить инструкцию по подключению:

```
При написании или обновлении PHPUnit-тестов прочитай файл PHPUnit13-full.md.
Файл содержит: запрещённые вызовы с заменами, новые assertions,
поведенческие ловушки и рекомендации по структуре тестов.
Следуй этим правилам при генерации кода.
```

Консолидированный файл не содержит мета-инструкций — только правила. Контекст о назначении файла обеспечивает скилл.
