# Capability Index

## Когда читать

- Перед поиском файлов, реализующих конкретное поведение / requirement.
- При исследовании capability или домена проекта.
- При планировании изменений (какие файлы затронуты?).

## Когда НЕ читать

- Уже знаешь конкретный файл (прямой Read).
- Задача не связана с capabilities (tooling, CI config, etc.).

## Путь навигации

1. Прочитай `INDEX.md` (этот же каталог) → домены и список всех тематик.
2. Найди нужную тематику → прочитай `topics/<topic>.yaml` для деталей.
3. Перейди к конкретному файлу исходников из поля `files` или `entry_points`.

Максимум 3 операции чтения от вопроса до файла.

## Ограничения

- **Read-only**: не создавай и не изменяй файлы в этой директории.
- Обновление индекса — ответственность Архиватора при `opsx:archive`.
