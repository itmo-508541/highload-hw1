## Purpose

Служебная ручка готовности: по её коду оркестратор (healthcheck docker compose)
и зависимые сервисы решают, можно ли направлять запросы к экземпляру сервиса.

## ADDED Requirements

### Requirement: Готовность сервиса
Сервис SHALL по запросу `GET /health` отвечать кодом `200`, когда он готов
принимать запросы к записям, то есть хранилище записей доступно. Когда
хранилище недоступно, сервис MUST отвечать кодом `503`. Тело ответа в обоих
случаях MUST быть JSON с заголовком `Content-Type: application/json`. Ручка
MUST быть доступна без аутентификации.

#### Scenario: Хранилище доступно
- **WHEN** хранилище записей отвечает
- **AND** клиент отправляет `GET /health` без заголовков аутентификации
- **THEN** ответ имеет код `200`
- **AND** `Content-Type` ответа — `application/json`

#### Scenario: Хранилище недоступно
- **WHEN** хранилище записей не отвечает
- **AND** клиент отправляет `GET /health`
- **THEN** ответ имеет код `503`
- **AND** `Content-Type` ответа — `application/json`
