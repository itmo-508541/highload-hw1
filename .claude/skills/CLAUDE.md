# .claude/skills/

Файлы здесь читает модель. Класть только то, что меняет её действия.

## `SKILL.md`

Состав: условие вызова, запреты, команды, порядок шагов, инварианты, чеклист.

`description` во frontmatter — это триггер. Описывать им то, что видно в коде
**до** поиска, а не выясненный ответ: условие вызова — незнание, а не
расположение или тип артефакта.

Скилл — рабочий цикл, а не справочник по библиотеке. Расхождение знания модели
с зафиксированной версией закрывается разделом `Model Knowledge Patch` —
точечно, «не пиши X → пиши Y», только по фактам, меняющим код.

Короткая причина рядом с правилом остаётся: она повышает исполнение.
Развёрнутая аргументация — нет.

## Где что лежит

Содержание распределяется по двум осям: механика конкретного действия против
правил, верных для всех действий, и файл скилла против файла правил того места,
куда ложится артефакт.

| | механика действия | правила для всех действий |
|---|---|---|
| в скилле | `Рабочий цикл` | `Чеклист` |
| в месте, куда ложится артефакт | — | файл правил места |

Левая нижняя клетка пуста: механику держит скилл.

Между двумя правыми клетками граница проходит по тому, **о чём правило**:

- правило о **проекте** — какие домены есть, где что регистрировать, какие
  команды, какая версия PHP — живёт только в файле правил места. Копия
  в скилле разъедется: правят то место, где сейчас работают;
- правило о **действии** — свойство инструмента, качество артефакта — живёт
  в скилле.

### Имя проекта в тексте скилла

Запрет касается не имён как таковых, а того, **чем имя работает в этом месте**.

| Имя работает | Где законно | Почему |
|---|---|---|
| выбором из реестра | только в файле правил места | реестр у проекта свой; копия разъедется молча |
| триггером вызова | `description` скилла | пользователь напишет именно так, иначе скилл не сработает |
| предметом запрета | тело скилла | «не править такой-то конфиг» без имени беспредметно |
| порогом или причиной | тело скилла, если имя верно у всех адресатов | короткая причина повышает исполнение |

Последняя строка — единственная, где нужна проверка: имя порога обязано быть
верным в каждом проекте, куда скилл поедет, и верным должно остаться
**утверждение целиком**, а не только имя. Совпадения имени мало: гейт
с одинаковым названием может запускать разный набор инструментов.

### Файл правил места

| Скилл | Файл правил места |
|---|---|
| кладёт файлы в каталог проекта | `CLAUDE.md` этого каталога (`tests/`, `features/`, `patterns/tests/`) |
| никуда не кладёт, но его выход потребляет другой скилл | `CONTRACT.md` рядом со `SKILL.md` |
| ничего не кладёт и потребителя не имеет | нет, и заводить не нужно |

Файл правил места агентский: `SKILL.md` на него **ссылается**, и цикл читает
его до того шага, чьи решения он ограничивает:

- держит **реестр допустимых значений** (домены, suite'ы, базовые классы,
  конвенции имён) — читается на первом шаге, иначе выбирать не из чего;
- держит **только формат выхода** — читается перед тем, как выход писать.

Файл бывает и тем, и другим сразу — тогда он читается дважды, и это норма,
а не дубль.

## Пункт чеклиста

Пункт законен, если несёт то, чего в остальном тексте скилла нет.

```
цикл:    «включить свет»
чеклист: «освещённость не более 10 люмен на квадратный метр»
```

Порог `10` в цикле не встречается — пункт несёт информацию. Пункт «свет
включён» её не несёт: это эхо шага, и его место в цикле.

Гейта два, и они разные. Цикл гейтит **по выполнению**: шаг либо сделан, либо
нет, и это видно по нумерации. Чеклист гейтит **по порогу**, а порог нумерацией
не выражается — под него секция и нужна.

Одно и то же наблюдение попадает в разные дома в зависимости от формулировки:
как действие — в цикл, как измеримое состояние результата — в чеклист.
Формулировать в ту сторону, где дом.

Чеклист без единого порога законен пустым: разделу нечего держать.

## `README.md` рядом со `SKILL.md`

Всё описательное, адресованное человеку: обоснование решений, разбор режимов
отказа, замеры, история редакций, проектные зависимости, которые надо
перепроверить при переносе в другой проект.

Из `SKILL.md` на него **не ссылаться** — иначе модель прочитает то, что вынесено,
чтобы она не читала.
