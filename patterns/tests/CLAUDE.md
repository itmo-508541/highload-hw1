# patterns/tests/

Каталог механик тестов проекта (PHPUnit и Behat): как устроена проверка,
не что проверяет домен.

## Что здесь лежит

- `INDEX.md` — оглавление: вид проверки → карточка → donor.
- Одна карточка — один файл `*.md` (не `CLAUDE.md`, не `INDEX.md`).
- Карточка указывает на donor: маленький существующий тест
  (или на саму карточку, если запись описывает каталог).

## Конвенции

- Имя файла и id в INDEX — механика (`http-api`), не домен.
- Схема карточки как у `tests-pattern-card.md`: When, Copy, Do not, Done when, donor.
- Новая карточка = копия `tests-pattern-card.md` + строка в INDEX.
- `Do not` — антиповедение этого же вида проверки, не отдельный файл.
- Карточку добавляет человек (явно, по классу ошибки).

## Запрещено

- Карточка без donor и без строки в INDEX.
- Id и When про конкретную фичу или сущность.
- Donor-простыня; копировать огромный соседний тест целиком.
- Писать карточку «задним числом» из суррогатного теста,
  пока человек не указал, какой класс ошибки фиксируем.
- Дублировать INDEX в этом файле.
