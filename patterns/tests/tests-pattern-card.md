# tests-pattern-card

- donor: `patterns/tests/tests-pattern-card.md`

## When

Добавляешь карточку механики в `patterns/tests/`.
Не когда пишешь код теста для PHPUnit, Context или `.feature` для Behat.

## Copy

1. Новый файл `patterns/tests/<id>.md` с секциями When, Copy, Do not, Done when, donor.
2. id и имя файла — механика проверки, не домен.
3. donor — маленький существующий тест того же вида; для этой карточки — этот файл.
4. В `Do not` — антиповедение этого вида проверки (как только что сделали не так).
5. Одна строка в `INDEX.md`: когда → файл карточки → donor.

## Do not

- Домен в id или When (фича, сущность, сценарий продукта).
- Карточка без donor и без строки в INDEX.
- Donor на сотни строк; копировать огромный соседний тест целиком.
- Отдельный файл «антипаттерна» вместо секции Do not.
- Карточка без указания человека, из суррогатного теста «задним числом».

## Done when

Файл карточки на месте, в INDEX есть строка, путь donor существует.
